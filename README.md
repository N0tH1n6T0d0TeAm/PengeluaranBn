Problem ❌
Our client is experiencing issues with their employees because the financial system still contains calculation errors. The system they use still relies on manual record-keeping and data entry via Excel. Not only that, but the Excel calculations they use are considered burdensome because they require organizing columns to clarify the data, and sometimes employees become overwhelmed by the large number of customers, leading to significant errors in transactions even though they are already using excel.

Solution ✅
- We tried to simplify their system by creating a POS (Point of Sale) system. By using the app, our clients can easily perform calculations and enter data. Not only that, but they can also adjust prices on the menu without having to use a pen and paper.
- After that, we generated a transaction history and monthly totals, so that users don’t need to contact anyone—they can simply view their transaction totals online—and there’s no need to print them out, which helps prevent the loss of any files.
